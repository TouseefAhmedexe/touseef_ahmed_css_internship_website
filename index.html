Frequently Asked Questions

Does this website use JavaScript?

No. Everything is HTML and CSS, including the highlighted link in the navigation.

How does the dark theme work?

The CSS reads the theme setting of your device. Switch your device to dark mode and the colors change.

Does the application form send a message?

No. The page has no server code, so sending the form only reloads the page.

What happens when I print the page?

The navigation, the hero buttons and photo, and the contact form are left out. The address of each external link is printed after its text.

Where is the code saved?

In a public repository on my GitHub profile, with one commit for each step.
